# Prime E Global Limited: Maritime & Blue-Economy Enterprise
**Akwa Ibom State, Nigeria**

A modern corporate portal for **Prime E Global Limited**, advancing sustainable maritime logistics, deep seaport facilitation, bunkering operations, offshore engineering, aquaculture, and ocean governance across the Gulf of Guinea.

---

## 🌊 Overview
PRIME-E is positioned as a premier maritime and blue-economy enterprise anchored in Akwa Ibom State, Nigeria. This web portal showcases the organization's strategic vision, core divisions, investment portfolio, and sustainable blue economy roadmaps.

### Key Pillars:
- **Maritime Logistics & Deep Seaport Operations** (Ibom Deep Seaport interface & offshore supply base)
- **Marine Energy & Bunkering** (Low-sulfur marine gas oil, offshore vessel replenishment)
- **Offshore Engineering & Shipbuilding** (Dry-dock maintenance, fabrication, subsea inspection)
- **Aquaculture & Blue Biotechnology** (Sustainable marine farming & coastal community empowerment)
- **Ocean Conservation & Maritime Governance** (Maritime security, green shipping compliance)

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or newer recommended)

### Running Locally
1. Clone the repository:
   ```bash
   git clone <YOUR_REPO_URL>
   cd "PRIME E"
   ```

2. Start the corporate preview server:
   ```bash
   npm start
   ```
   *(or `node serve.js`)*

3. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

Alternatively, open `index.html` directly in any modern web browser.
